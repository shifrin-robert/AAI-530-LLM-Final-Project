# Generalization set

**Status: run on 2026-11-15** with prompts v2 and v3, three times each, and scored automatically.
The results are in the [Results](#results-2026-11-15) section below. No case or answer has been
reviewed by a person yet.

Prompt v3 was written to fix one benchmark case, CF-02 (two spending figures reported as of
different dates), and it did so in 3 of 3 runs. A result on the case a rule was written for can't
show that the rule generalizes. These 10 cases test the same situation on new documents. They also
test the situations where the rule could do harm: answering with a historical figure instead of the
current one, keeping an original budget that was replaced, treating agreeing figures as conflicting,
and losing a genuine contradiction.

## How the set was made

* **When and by whom.** Written on 2026-11-15 by Claude Code, from five situations named by the
  team, before any model was run on them. No model output was used to write the cases, their
  reference answers or their criteria.
* **Documents.** Six documents for three new fictional organizations: Meadowbrook Community Health
  Center, Pinecrest Unified School District and Harlow Arts Council. All names and figures are
  invented, and none appears in the 40-case benchmark or in any prompt. A test checks that prompt
  v3's example values are absent.
* **Files:**
  * cases and reference answers: [cases.json](cases.json)
  * relationship annotations for the revised conflict rule: [relationships.json](relationships.json)
  * documents: `evaluation/fixtures/generalization/`, generated by
    `python -m evaluation.build_generalization_fixtures`
* **Not yet reviewed.** No team member has verified the cases (`reference_verified_by_human` is
  false).

## Checks already done (offline, no model)

`tests/test_generalization_set.py` checks the following:

* every required fact is on the expected page of the generated PDFs;
* every required value reaches the passages that would be sent to the model, so these cases test
  the answer, not the search;
* the PDFs match their generator;
* the cases and documents are separate from the benchmark;
* the runner and the scoring audit run end to end with the offline extractive baseline. This only
  checks that the pipeline works; it is not a model result.

## Criteria, fixed before any run

v3 is judged to generalize to this set only if all of these hold. "Passes" means the original
per-case rule: the required facts and an accepted status.

1. **Dated values** (GEN-01, GEN-02): v3 passes at least 5 of its 6 case runs, and no fewer than v2.
2. **Current and revised values** (GEN-03 to GEN-06): v3 passes no fewer case runs than v2. The
   revised relationship rule also finds no v3 answer that presents an earlier value as current.
3. **Compatible figures** (GEN-07, GEN-08): no v3 run flags a conflict (0 of 6).
4. **Contradictions** (GEN-09, GEN-10): v3 passes no fewer case runs than v2.
5. **Length:** the mean answer length on these cases grows by less than 10% compared with v2.

Even if all five hold, 10 cases run 3 times is a small sample. The result would be consistent with
the rule generalizing, not proof that it does.

## Results (2026-11-15)

**Runs:** `evaluation/results/generalization/20261115T060208Z_openai_gpt-6-luna_v2_gen-v2-x3` and
`evaluation/results/generalization/20261115T060343Z_openai_gpt-6-luna_v3_gen-v3-x3`. The revised-rule audit is in
`evaluation/audit/generalization/`.

The cases, reference answers, annotations, documents, scoring code and prompts were checksummed
before the runs and were unchanged afterwards.

| Situation (2 cases, 3 runs each) | Prompt v2 | Prompt v3 |
|---|---|---|
| Spending reported on two dates (GEN-01, GEN-02) | 2 / 6 | 6 / 6 |
| Current and historical figure (GEN-03, GEN-04) | 6 / 6 | 6 / 6 |
| Revised and original budget (GEN-05, GEN-06) | 6 / 6 | 6 / 6 |
| Compatible figures (GEN-07, GEN-08), no conflict flagged | 6 / 6 | 6 / 6 |
| Genuine contradiction (GEN-09, GEN-10) | 6 / 6 | 6 / 6 |
| **All case runs** | **26 / 30** | **30 / 30** |

* **Where v2 failed:** all four failures kept only the latest figure, for example "Spending to date
  was $702,500 as of May 15, 2026."
* **Regressions:** none at case level, under the original or the revised scoring.
* **Criteria:** v3 met all five fixed before the run.
* **Significance:** the difference is not significant. On the dated cases Fisher's exact test gives
  p = 0.061, and the runs are repeated measurements of the same questions.
* **Cost:** $0.0112 for both runs, computed from token counts.

These are automatic scores on synthetic documents. They show only that the dated-figure rule
carried over to new documents and wording for questions about spending to date. They do not show
accuracy on arbitrary documents. Full analysis: `docs/EVALUATION_REPORT.md`, Section 7.5.
